# Chùa An Nhiên — Đi chùa online 🪷

Ngôi chùa 3D trực tuyến: thắp hương, gõ mõ, thỉnh chuông, niệm Phật 108 biến, cây nguyện ước,
bàn thờ gia tiên (lịch âm, ngày giỗ), trò chuyện, điểm danh và hẹn giờ lên chùa cùng mọi người.

- Mở chùa: https://tracyha1987.github.io/chua-an-nhien/
- Dữ liệu dùng chung: Firebase Realtime Database (dự án `chua-an-nhien`), đăng nhập ẩn danh.
- Nhạc nền và âm thanh do Claude tạo riêng cho Chùa An Nhiên.

Không đại diện cho chùa hay tổ chức tôn giáo nào. Không nhận tiền cúng dường.
